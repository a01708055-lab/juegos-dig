# 🎮 Juegos Retro

## Descripción
Este proyecto es un sitio web de juegos retro que reúne diferentes videojuegos clásicos en una sola página.

## Juegos incluidos
- **Crossy:** juego para esquivar obstáculos.
- **Gato:** juego clásico de tres en raya.
- **Pong:** juego de tenis de mesa.
- **Snake:** juego de la serpiente.
- **Tetris:** juego de bloques.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
